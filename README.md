# MHF4U Real-World Functions CCT website

Static site for GitHub Pages. No build step.

```
index.html
css/style.css
images/            (21 images, already exported from MHF4UCCT.docx)
README.md
```

Deploy: push these files to a repo, then Settings > Pages > Deploy from a branch > main / (root).
Math is rendered with KaTeX loaded from cdnjs, so the page needs an internet connection.
